如果你想实现**类似 .NET Aspire 的本地观测方案**（即 **无外部服务，但有完整 metrics / traces / logs / dashboard**），推荐的架构是：

**核心思路：复用 OpenTelemetry 的本地管道，但把 Collector、存储、展示都嵌入到单体应用中。**

这样你可以获得：

* Metrics（QPS / 错误率 / RT）
* Traces（每个请求链路）
* 最近请求列表
* 服务拓扑
* 请求趋势
* Dashboard UI

同时仍然保持：

* **0 外部服务**
* **单体部署**
* **Aspire 同款观测模型**

下面是完整实现方案。

---

# 一、总体架构（Aspire 本地模式）

Aspire 的本质结构其实是：

```
App
 ├─ OpenTelemetry SDK
 ├─ OTLP Export
 └─ Aspire Dashboard
```

如果自己实现，可以做成：

```
                    ┌─────────────────────┐
                    │   Local Dashboard   │
                    │  (metrics + trace)  │
                    └─────────▲───────────┘
                              │
                    InMemory Telemetry Store
                              │
Client → Middleware → YARP → Service
                 │
                 ▼
        OpenTelemetry Activity
```

关键组件：

| 组件                   | 作用           |
| -------------------- | ------------ |
| YARP instrumentation | 采集请求         |
| OpenTelemetry        | 统一 telemetry |
| InMemory exporter    | 本地存储         |
| Dashboard            | 展示           |

涉及技术：

* YARP
* ASP.NET Core
* OpenTelemetry

# 三、YARP Telemetry 采集

在 YARP pipeline 中创建 Activity。

```csharp
public class GatewayTelemetryMiddleware
{
    private static readonly ActivitySource Source =
        new("Gateway");

    private readonly RequestDelegate next;

    public GatewayTelemetryMiddleware(RequestDelegate next)
    {
        this.next = next;
    }

    public async Task Invoke(HttpContext ctx)
    {
        using var activity = Source.StartActivity(
            "gateway.request",
            ActivityKind.Server);

        var sw = Stopwatch.StartNew();

        await next(ctx);

        sw.Stop();

        activity?.SetTag("route",
            ctx.GetEndpoint()?.DisplayName);

        activity?.SetTag("status",
            ctx.Response.StatusCode);

        activity?.SetTag("duration",
            sw.ElapsedMilliseconds);
    }
}
```

注册：

```
app.UseMiddleware<GatewayTelemetryMiddleware>();
app.MapReverseProxy();
```

# 五、本地 Telemetry Store（Aspire 同款）

Aspire Dashboard 的核心其实是一个 **内存 Telemetry Store**。

实现一个：

```
TelemetryStore
```

保存：

| 类型      | 存储          |
| ------- | ----------- |
| metrics | time series |
| trace   | 最近 N 条      |
| logs    | ring buffer |

示例：

```csharp
public class TelemetryStore
{
    public ConcurrentQueue<Activity> Traces = new();

    public ConcurrentDictionary<string,
        List<MetricPoint>> Metrics = new();
}
```

限制：

```
max traces = 2000
max metrics points = 24h
```

# 六、本地 Exporter（关键）

OpenTelemetry 默认 export：

```
OTLP
Prometheus
Jaeger
```

但我们需要：

```
InMemoryExporter
```

实现：

```csharp
public class LocalTraceExporter : BaseExporter<Activity>
{
    private readonly TelemetryStore store;

    public override ExportResult Export(
        in Batch<Activity> batch)
    {
        foreach (var item in batch)
        {
            store.Traces.Enqueue(item);
        }

        return ExportResult.Success;
    }
}
```

注册：

```csharp
builder.Services.AddOpenTelemetry()
    .WithTracing(t =>
    {
        t.AddSource("Gateway");

        t.AddProcessor(
            new SimpleActivityExportProcessor(
                new LocalTraceExporter(store)));
    });
```
